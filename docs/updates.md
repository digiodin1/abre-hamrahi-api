# Application updates

Windows and Android check the stable Releases of `digiodin1/abre-hamrahi-api` on GitHub at startup and at most once every six hours while running. Settings includes a manual check and a download/install button. No account tokens or local folder information are sent to GitHub.

Only a numerically newer stable version with the exact platform installer name, an uploaded asset, valid publication date, size and SHA-256 digest is accepted. Preview and draft releases are ignored. Downloads use HTTPS and a fixed GitHub host allowlist, bounded buffers and temporary files. Corrupt or interrupted downloads never run. GitHub asset SHA-256 is the integrity source, not a separate publisher signature. Android additionally checks the APK package, higher version code and signing certificate against the installed application.

The upgrade deadline is **30 days after the newer stable release's publication time**, not after installation of the old application or the first update check. After that deadline, new sync/verification runs are blocked until upgrading. A transfer already running may finish safely; settings, reports and local preview remain available. The last known deadline is saved locally and still applies during an outage. If GitHub cannot be reached before any update has been discovered, the app does not invent an update or deadline. A successful newer-release check can change the target release and its deadline. This is an application policy, not tamper protection against the device owner changing the clock or local state.

Windows downloads and verifies the setup file before closing the app, waits for the process to exit, runs the current-user installer in the same installation directory, then restarts with the same data directory/port and no browser tab. It requires the packaged Windows executable; source installations must update using their package manager. The installer does not delete account state, sync indexes or startup configuration. A failed download leaves the running program intact. If installation fails, run the original shortcut and retry.

Android downloads internally and opens Android's system package installer. The user must grant this application permission to install packages and confirm the installation; the application cannot silently bypass Android's security controls. This APK is distributed directly through GitHub. Test updates on an Android device before deploying to a wider fleet.

For maintainers: publish the matching `AbreHamrahiAPI-X.Y.Z-windows-x64-setup.exe` and `AbreHamrahiAPI-X.Y.Z-android.apk` in a stable `vX.Y.Z` release. Preserve the Android signing key and increment its version code. Prefer uploading assets to a draft and publishing only when they are complete. GitHub must supply a `sha256:` digest for each installer. Version 1.7.5 is the first release with this updater; earlier installations need one manual upgrade.
