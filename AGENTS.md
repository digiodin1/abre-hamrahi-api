# Abre Hamrahi API

- هنگام تحویل هر نسخهٔ پایدار، کد و بسته‌های ویندوز و اندروید را در GitHub Releases همین مخزن منتشر کنید. یادداشت انتشار و راهنمای نصب یا ارتقا باید فارسی باشد.
- از [روال انتشار](docs/releases.fa.md) استفاده کنید. پیش از عمومی‌کردن نسخه، نام، نسخه، امضای اندروید و هش بسته‌ها را بررسی کنید. داده‌ها، تنظیمات، نشست‌ها و کلیدهای خصوصی نباید وارد مخزن یا بسته‌ها شوند.
