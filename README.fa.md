# Abr Hamrahi API

Abr Hamrahi API یک پنل محلی و رایگان برای پشتیبان‌گیری یک‌طرفه و نسخه‌دار از پوشه‌های ویندوز به ابرهمراهی است. پیش از ارسال، فایل‌ها snapshot و با SHA-256 بررسی می‌شوند؛ نسخه‌های قدیمی و حذف‌های محلی از ابر پاک نمی‌شوند.

این پروژه اتصال رسمی نیست. در تاریخ ۴ نوامبر ۲۰۲۶، قرارداد پایدار و عمومی API یا WebDAV برای این گردش‌کار پیدا نشد؛ بنابراین پاسخ‌های ناشناخته عمداً باعث توقف امن عملیات می‌شوند و ممکن است تغییر سرویس به به‌روزرسانی آداپتر نیاز داشته باشد.

پنل فقط روی `127.0.0.1` گوش می‌دهد، اتصال غیرمحلی را رد می‌کند، مسیر آزاد برای خواندن فایل ندارد و برای نشانی‌های انتقال ابری تغییر DNS را بررسی می‌کند. سرویس ابرهمراهی نمی‌تواند از این API به رایانهٔ شما اتصال برگشتی بگیرد؛ برنامهٔ مخربی که از قبل با کاربر ویندوز شما اجرا شده باشد خارج از محدودهٔ حفاظت این ابزار است.

## نصب سریع ویندوز

```powershell
py -m venv .venv
.\venv\Scripts\Activate.ps1
python -m pip install .
abr-hamrahi-api
```

پنل روی `127.0.0.1` اجرا می‌شود و مرورگر فقط برای نمایش پنل است؛ زمان‌بندی تا وقتی پردازش برنامه روشن باشد ادامه دارد. اطلاعات خصوصی در `%LOCALAPPDATA%\AbrHamrahiAPI` نگه‌داری می‌شود و داخل پوشهٔ نصب یا مخزن قرار نمی‌گیرد.

## ترتیب استفاده

۱. وارد حساب شوید و در صورت نیاز ثبت‌نام یا پذیرش مقررات را در سایت رسمی کامل کنید.

۲. پوشه‌ها را اضافه و تنظیمات را ذخیره کنید. پوشهٔ state برنامه، ریشهٔ دیسک و symlink پذیرفته نمی‌شوند.

۳. پیش‌نمایش بدون ارسال را اجرا کنید، سپس بررسی ظرفیت و آزمون آپلود/بازیابی فایل کوچک را انجام دهید.

۴. پس از موفقیت آزمون، پشتیبان‌گیری را اجرا کنید. بازیابی عمداً دستی است: فایل نسخهٔ دلخواه و manifest همان نوبت را از ابر دریافت کنید.

به‌صورت پیش‌فرض فایل‌های محیطی، کلیدهای خصوصی، credentialها، فایل‌های موقت و پوشه‌های وابستگی کنار گذاشته می‌شوند. این برنامه رمزنگاری سرتاسری ندارد؛ برای دادهٔ بسیار حساس، پیش از انتخاب پوشه آن را جداگانه رمزگذاری کنید.
